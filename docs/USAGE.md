# 使用说明

## 安装与启用

确认「小米设置」包名为 `com.xiaomi.misettings`，版本为 `16.4.260829.00`、versionCode 为 `260829400`，且设备已有可用的 LSPosed 环境。模块只适配这一目标版本。

1. 从 [Releases](https://github.com/PutFounder5297/XiaomiFocusMode/releases) 下载 APK。
2. 等待当前专注结束后安装。
3. 在 LSPosed 中启用模块，作用域仅选择「小米设置」。无需勾选桌面、SystemUI 或系统框架。
4. 重启手机，打开模块进入原生专注设置。
5. 设置时长并开始专注；通过模块入口或通知返回，检查剩余时间未重置。

## 功能边界

固定应用名单由源码维护，界面只读，不提供自由编辑入口。模块保留小米原生计时和历史，不提供提前结束专注或绕过应用锁的入口。

自定义整数时长范围为 1–35791 分钟。重复进入应返回同一原生会话并保留起始时间。超级岛沿用 `buttons-free-v2` 模板，无按钮或厂商计时器字段。

模块首页可显示在最近任务中。原生倒计时任务请求排除最近任务；可在切回桌面、打开微信后检查卡片是否残留。后台保护不能保证抵抗强行停止或全部系统清理方式。

## 升级与停用

升级前等待当前专注结束。原签名私钥未在恢复的备份中，开发者自行构建的 APK 使用不同签名，无法覆盖原发布版。需要切换签名时，应在专注结束后卸载旧模块，再安装新包、重新启用并重启；卸载会清除模块自身数据。

正常停用时，先等专注结束，再在 LSPosed 关闭模块并重启；无需清除小米设置数据。

## 排查与反馈

遇到问题先核对目标应用版本、模块版本及 LSPosed 作用域，并使用模块中的独立排障入口。反馈时提供设备和 ROM 版本、复现步骤、期望与实际行为。日志只附与问题有关且已脱敏的片段，不上传系统 APK/JAR 或完整私人日志。

主机测试和静态检查不能证明所有手机功能正常。原版本的验证范围见 [归档状态](ARCHIVE_STATUS.md)。
